# @shanhai/kaipu-platform · 场地插件

**场地插件是开铺的核心。** 装了它，你的 DeepSeek Harness 里就有了「开铺的场地」—— 场景、运行记录、运行视图、报告，都在这里。

> 它**不含**我方自有的 Agent 资产（那是智囊团插件的事，见同仓的 `plugin-wisdom`）。

## 它做什么

| 能力 | 说明 |
|:--|:--|
| **总台** | Agent 卡片与场景卡片，左栏一览 |
| **运行视图** | 逐灯步骤与判定路由，看得见走到哪一步 |
| **角色位** | 执行 / 审计 / 管理三类位子；签字位属平台效力锚点，不可派人 |
| **能力边界页** | 这个场地**做不到什么**，完整列出，不含糊 |
| **自定义场景** | 自己登记场景，登记即生效 |
| **报告面** | 跑完的项目出结构化报告 |

## 数据从哪来

**本包是客户端，不是数据源。** 场景、运行记录、席位、留痕都在服务端，本包通过约定的接口去读。

装好默认连的是我们提供的服务。想接你自己的部署，在 DSH profile 的配置覆盖层里改 `baseUrl` / `accountId` 即可 —— 不需要改本包任何文件。

## 它不含什么（重要）

- ❌ 服务端的判断标准与规则库全文 —— 那些只在服务端
- ❌ 任何密钥、任何客户数据
- ❌ 内部质检脚本

本包发布的 `lib/` 就是发到每台用户机器上的那一份。真正的判断逻辑在服务端，不在这个包里。

## 怎么装

```sh
dsh plugin add @shanhai/kaipu-platform
```

或在插件市场里搜「山海·开铺」。装完重启宿主。

另外两个包（`@shanhai/kaipu-workstation` 工位操作台、`@shanhai/kaipu-wisdom-team` 智囊团面板）是**可选**的，各自独立安装、独立卸载；它们的数据都来自本包接入的服务端，单独装会如实显示「通道未就绪」。

## 兼容性

- 宿主：DeepSeek Harness
- `react` 由宿主提供（peer dependency），不需要你另外装
- Node >= 22
