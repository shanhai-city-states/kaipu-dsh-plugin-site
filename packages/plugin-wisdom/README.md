# @shanhai/kaipu-wisdom-team · 智囊团插件

**配套侧边面板：展示内置谋士团队与席位状态。**

> ★ **可装可不装。** 卸掉它，场地插件仍完整可用。
>
> ⚠️ **但它不能单独工作。** 灯位数据由开铺的场地插件（`@shanhai/kaipu-platform`）提供。
> 只装本包时，面板会**如实显示**「数据通道未就绪 —— 灯位数据由『开铺』场地插件提供」，
> 而不是显示成「没有任何灯位」。这是诚实降级，不是故障。
>
> ⇒ **建议与 `@shanhai/kaipu-platform` 一起安装。**

## 它做什么

- 侧边栏一个面板，展示内置的谋士（智囊）团队
- 显示每个席位的状态：谁在位、谁空着
- 数据来自场地插件接入的服务端，本包自己不存数据

## 名字为什么叫「智囊团」

「专家团」是一组专家，是**能力的集合**；「智囊团」是一群谋士，是**会商量的组织**。

按流程组团，本质是会商流程，不是并行调用。名字要装得下这件事。

## 它不含什么

- ❌ 服务端的判断标准与规则库全文
- ❌ 任何密钥、任何客户数据
- ❌ 内部质检脚本

## 怎么装

```sh
dsh plugin add @shanhai/kaipu-wisdom-team
```

装完重启宿主，侧边栏会多出智囊团面板。
